# 表格数据洞察

目标不是堆图表，而是回答“发生了什么、为什么值得注意、下一步验证什么”。

## 工作流程

1. 识别每一列含义、数据类型、时间范围、统计口径和缺失值。
2. 复述要回答的问题；用户未提出问题时，先完成一次通用体检。
3. 检查重复、缺失、异常值、单位混用、日期错误和样本偏差。
4. 计算必要的总量、比例、变化、分布和分组对比。
5. 把观察、解释和建议分开：数据能证明的是观察，原因通常只是待验证解释。
6. 推荐最少且最合适的图表，不为装饰做图。

## 默认输出

```markdown
# 数据结论

## 先看这三件事
1. [最重要发现 + 数字证据]
2. ...
3. ...

## 数据质量
- [缺失、异常、口径或样本限制]

## 关键发现
- 观察：...
- 可能解释：...
- 还需要验证：...

## 建议动作
1. [动作] — 验证指标：[指标]

## 推荐图表
- [图表类型]：用于说明 [关系]
```

## 安全与准确性

- 默认只读原始文件，清洗或转换时另存副本。
- 关键计算说明公式或口径，使结果可以复核。
- 小样本、相关性和因果关系要明确提示限制。
- 涉及财务、投资、医疗或法律决定时，只提供分析，不代替专业判断。
- 输出中避免暴露个人身份信息；必要时先做脱敏。
