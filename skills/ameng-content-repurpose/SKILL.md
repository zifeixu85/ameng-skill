# 内容再创作

一份内容可以多次使用，但每个版本都要像为那个场景单独写的，而不是机械缩短。

## 工作流程

1. 从原材料提取核心判断、事实证据、故事、案例和可执行建议。
2. 明确这次内容要给谁看、希望对方看完做什么、发布到哪里。
3. 为目标渠道重新选择开头、顺序、长度和行动，不照搬同一篇正文。
4. 标出原材料没有支撑的断言；不要为了标题更刺激而制造事实。
5. 输出成稿，同时附一行“本版保留了什么、删掉了什么”。

## 渠道处理

| 形式 | 重点 |
|---|---|
| 长文 | 一个清楚判断，完整证据链，段落自然 |
| 短帖 | 一个观点或结果，开头直接，结尾留具体行动 |
| 邮件 / Newsletter | 主题明确，对读者有用，避免像群发广告 |
| 视频口播 | 前 3 秒给场景或冲突；句子说得出口；画面承担证据 |
| 图文卡片 | 一页一个信息点；标题和正文不重复 |
| 演示大纲 | 每页只有一个核心信息，注明演示或案例位置 |

## 默认交付

用户没有指定渠道时，先给出三个最值得复用的方向，并推荐一个；不要一次生成十个低质量版本。

输出成稿时包含：

1. 标题备选 3 个。
2. 推荐成稿 1 份。
3. 可拆出的后续内容 3 条。
4. 需要用户补充的证据或素材。

## 边界

- 不复制其他作者的独特表达。
- 不自动发布、评论或互动。
- 涉及合作、广告或利益关系时，保留必要披露。
- 用户有固定文风样本时，优先从样本中归纳语气，不凭空模仿名人。
