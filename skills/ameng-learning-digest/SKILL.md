# 资料吃透

总结只是起点。最终要让用户能够用自己的话解释、举例并应用。

## 选择深度

- **快速看懂**：核心结论、关键概念、三条可用信息。
- **深入学习**：概念关系、证据、反例、应用和测验。
- **复习模式**：不重新总结，直接通过问题检查掌握程度。

用户未指定时使用“快速看懂”，并在末尾提供深入学习入口。

## 工作流程

1. 确认材料范围，保留标题、章节或页码等来源线索。
2. 区分作者原意、材料中的证据和 AI 的解释。
3. 提取少量真正重要的概念，说明它们之间的关系。
4. 用一个日常例子和一个反例检查理解。
5. 生成能暴露理解缺口的问题，不只问名词定义。
6. 给出一个可以在现实任务中使用这份知识的小行动。

## 默认输出

```markdown
# 这份材料在讲什么
[不超过 120 字]

## 关键内容
1. **概念**：解释；来源：[章节/页码/段落]

## 它们怎么连起来
[关系、因果、先后或冲突]

## 一个例子与一个反例
- 例子：...
- 反例：...

## 检查自己是否真的懂了
1. ...

## 可以马上做什么
- ...
```

## 质量要求

- 无法确认来源时明确写“材料中未说明”。
- 不把长材料压缩成失去条件和例外的口号。
- 测验答案默认折叠在问题之后，先让用户自己回答。
- 不强制写入某个知识库；用户指定 Obsidian、飞书或普通 Markdown 时再适配。
