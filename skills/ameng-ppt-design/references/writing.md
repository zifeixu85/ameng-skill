# 内容与叙事

## 先定骨架

同样的素材，骨架不同，整份 deck 就不同。

| 骨架 | 用在 | 顺序 |
|---|---|---|
| 结论先行（默认）| 汇报、路演、决策 | 结论 → 三条理由 → 证据 → 要什么 |
| 故事线 | 主题演讲、品牌、复盘 | 钩子 → 背景 → 核心 → 转折 → 带走什么 |
| 教学步骤 | 教程、SOP | 为什么 → 准备 → 第 1…N 步 → 练习 |
| 逐项展示 | 作品集、功能巡览 | 定调 → 每项同版式 → 收束 |
| 简报速览 | 晨会、状态同步 | 一页全局 → 分块逐条 → 下一步 |

页数：15 分钟约 10 页，30 分钟约 20 页，45 分钟约 25–30 页。内容装不下时把取舍摆给用户，不要偷偷删。

## 节奏

重页之后接轻页。大字页、图表页、结构页交替。全份至少五种版式，图形页至少四成。

## 文案

- 标题是一句结论。
- 不写「赋能、打造、抓手、闭环、全方位」这类空话。「不是…而是…」全份最多两次。
- 不用 emoji 当图标。全大写小标签（`.kicker`）全份最多三个。
- 编号只给真正有顺序的内容。

## 并列内容

三个方案、四种做法这类并列的列，每列写同样的几项：一句介绍、优势、劣势。一列详细、一列只有标题，看起来就是没做完。推荐项只有一个。

## 署名和联系方式

结尾页不默认放公司名。用 `.contacts` 放讲者自己的渠道，内容按这场活动定：

```html
<div class="contacts"><span><b>公众号</b>…</span><span><b>网站</b>…</span></div>
```

`paper` 的印章只有写了 `data-seal` 才出现。

## 讲者备注

`.notes` 既是提词，也是配音稿，写成能直接念的口语：

- 不写「过渡」「要点」「时长」这类标记。
- 数字写读法：「百分之七十三」。
- 过渡句写进下一页开头。

## 诚实

数字必须有出处，示例必须标 `data-sample`。没有的数据不编。
