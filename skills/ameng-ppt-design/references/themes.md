# 主题

六套主题是六种气质，不是换色。写到 `<main class="deck" data-theme="…">`，放映时在工具条「主题」里随时切。

| 主题 | 气质 | 适合 | 主色 |
|---|---|---|---|
| `paper` 纸墨 | 纸、墨、朱砂，粗宋标题，留白 | 方寸无尽对客、课程、品牌 | 朱砂 |
| `noir` 夜幕 | 深底巨字，右侧日出光 | 发布会、路演、主题演讲 | 橙 |
| `swiss` 网格 | 硬网格、齐左、黑白红 | 数据汇报、要显得严谨的场合 | 信号红 |
| `spec` 规格 | 冷灰面板、点阵数字、等宽批注 | 技术分享、AI 产品、架构 | 信号橙 |
| `block` 色块 | 大几何、圆润、弹性动效 | 课程、社群、创意提案 | 番茄红 + 少量明黄 |
| `board` 董事会 | 结论句标题、证据、出处 | 诊断、方案、董事会汇报 | 松绿 |

拿不准：对客用 `paper`，上台用 `noir`，看数据用 `swiss`。

切换只是换样式，内容不重新生成，不用 AI。六套都不合适时，按 [custom-style.md](custom-style.md) 生成一套。

## 主题色

```html
<main class="deck" data-theme="swiss" data-accent="#1E5AA8">
```

文字和标记用这个颜色，色块自动压暗到白字读得清。客户有品牌色时用它。没有指定时不用蓝色。

## 单页明暗

`<section data-tone="dark">`、`data-tone="accent"`（主色满版）、`noir` 还可用 `data-tone="light"`。主题已经给封面、章节页、结尾页配好了，一般不用写。`T` 键整份反转。

## 明暗要两边都能看

放映时按 T 会整体反转明暗。手绘 SVG、表格高亮都要在两边读得清，交付前跑一次 `check.mjs <deck> --invert`。

## 两条硬规矩

1. **深色或饱和色块上的文字一律白色。** 只有明黄、奶白这种浅色块才用深色字。这条写在 `kit/core/fills.css`，用 `.is-hot`、`.kpi--hot` 就自动对；`check.mjs` 会读文字背后的真实像素，错了直接拦下。不要因为对比度数值过关就用深色字。
2. **颜色收敛。** 一种主色 + 墨色 + 纸色，最多一种小面积点缀。不按章节轮换整页颜色。
