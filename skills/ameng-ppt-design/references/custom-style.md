# 按描述生成风格

用户说「六套都不满意」「我想要……的感觉」，或给了参考图、品牌手册时，用这一篇。内容不用重做，只新增一套样式。

## 步骤

1. **定方向**：用三个词复述用户要的气质，说出它从哪来（材质、年代、行业、一件具体的东西）。描述够具体就直接做；太笼统（比如「高级一点」）只问一句，给两个方向选。
2. **选基础主题**：挑构图最接近的，版式、节奏、动效都继承。

   | 要的感觉 | 基础 |
   |---|---|
   | 纸感、人文、东方、杂志 | `paper` |
   | 深色、舞台、科技、奢华 | `noir` |
   | 理性、硬朗、现代主义 | `swiss` |
   | 工程、仪表、复古科技 | `spec` |
   | 活泼、童趣、海报、几何 | `block` |
   | 商务、金融、咨询、政务 | `board` |

3. **建文件**：
   ```bash
   node scripts/new-style.mjs <deck> <英文id> --name "中文名" --base paper --decor
   ```
4. **改 `styles/<id>.css` 的颜色和字体**，按下面的规则。
5. **加一个招牌细节**：一种贯穿全份的处理，比如强调字的方式、封面的一个图形。写在 CSS 末尾；要画图形就写 `styles/<id>.js` 的 `decor`，返回真实 DOM 或 SVG，这样导出后是可编辑形状。不要用伪元素画主要图形。
6. **检查**：跑 `check.mjs` 必须 PASS；`shots.mjs` 出图，至少看封面、章节、图表、色块页四种；跑 PPTX 自查。
7. **交付**：用户刷新网页，新风格排在「主题」菜单最上面。不满意就改这个文件，不动内容。

## 配色规则

- 一种主色 + 墨色 + 纸色，最多一种小面积点缀。不要因为用户说了很多颜色就全用上，挑一个当主角。
- `--brand` 是带文字的色块，白字对比度至少 4.5。`--accent` 是文字和标记用的，可以比它亮。
- 深底主题里 `--accent` 要够亮，浅底主题里要够深。
- `--c1` 到 `--c4` 是图表色：第一色用主色，其余用墨色和中性色的深浅，相邻两色要拉开。
- 三个换底（`dark`、`accent`，有的还有 `light`）都要改，别只改主色。
- 用户明确要蓝色就用，没说就别默认用蓝。

## 字体规则

- 优先用 `kit/fonts/` 里的：思源黑体 `Noto Sans SC`、思源宋体 `Noto Serif SC`、得意黑 `Smiley Sans`、`Archivo`、`Bricolage Grotesque`、`Instrument Sans`、`Instrument Serif`、`Newsreader`、`JetBrains Mono`、`Doto`。
- 不加载网络字体。确实要别的字体，把开源字体文件放进 deck 的 `styles/`，用 `@font-face` 引入，并告诉用户 PPTX 里会换成系统字体。
- 字体栈末尾写上 `serif` 或 `sans-serif`，导出 PPTX 时靠它选替代字体。

## 装饰的位置

- 页眉（y 40–92）、页脚（y 1000–1050）和文字区不放图形，`check.mjs` 会拦下压住页眉页脚的装饰。
- 主图形放右侧或角落，给左侧标题留足位置。

## 不能动的

- 字号上限（见 layouts.md）。气势靠构图和留白。
- 色块上的白字规则。`fills.css` 会强制，不要绕开。
- 版式的 HTML 结构。

## 风格写得好不好

- 看封面能说出它像什么，不是「好看的配色」。
- 换成别的内容也成立，不依赖某一页的文字。
- 和六套内置主题放一起，一眼能区分。只换了颜色的话，回到第 5 步。
