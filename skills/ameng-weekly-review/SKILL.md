# 周报与复盘

把流水账整理成结果，把结果变成下一步。不要为了显得忙而夸大工作量。

## 先判断模式

- **对外周报**：给团队、客户或管理者看，强调结果、风险和下一步。
- **个人复盘**：给自己看，强调判断、经验、阻塞和改进。
- **两者都要**：先输出对外版，再输出个人版；不要混成一篇。

输入不完整但足够整理时直接开始，把真正影响结论的缺口标为“待补充”。

## 整理方法

1. 按项目、目标或结果归类，不按周一到周日排列。
2. 区分“完成了什么”“产生了什么结果”“还有什么没解决”。
3. 保留能证明进展的数字、链接、文件和反馈；没有证据时不要编数字。
4. 找出本周最值得保留的一条经验，以及应该停止的一件低价值事情。
5. 把下周计划压缩成最多三件真正重要的事，并写清完成标准。

## 默认输出

```markdown
# 本周回顾

## 完成与结果
1. **[事项]**：[结果、影响或证据]

## 进行中与风险
- [当前状态]；下一步：[动作]；风险：[风险或待确认]

## 本周复盘
- 做对了：...
- 需要调整：...
- 新发现：...

## 下周最重要的三件事
1. [动作] — 完成标准：[可验证结果]
```

## 写作要求

- 使用自然、直接的中文，删除“赋能、闭环、抓手、持续推进”等空话。
- 不把参与、沟通、关注写成已经完成的结果。
- 对外版控制在一屏到两屏；个人版可以更诚实，但仍要具体。
- 用户提供上一期周报时，主动对照上期承诺是否兑现。
